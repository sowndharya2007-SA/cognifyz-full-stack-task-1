# ✨ Full Stack Contact Portal

A modern server-rendered contact portal developed as part of the
Cognifyz IT Solutions Full Stack Development Internship.

The project demonstrates how a frontend HTML form communicates with
a Node.js and Express backend, with EJS used for dynamic server-side
HTML rendering.

---

## 🚀 Features

- Responsive pastel UI
- HTML form structure
- Node.js backend
- Express server
- POST form submission
- Server-side form validation
- EJS server-side rendering
- Dynamic success and error states
- Client-side form interaction
- Live message character counter
- Submit loading state
- Mobile-responsive layout

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Form structure |
| CSS3 | Responsive UI and styling |
| JavaScript | Client-side interaction |
| Node.js | Server runtime |
| Express.js | Backend server and routing |
| EJS | Server-side rendering |
